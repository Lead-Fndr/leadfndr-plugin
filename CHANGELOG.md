# Changelog

## 1.0.0 — 2026-11-11

- Initial public plugin: remote Lead Fndr assistant connection at `https://api.leadfndr.com/api/v1/mcp`.
- Setup field for a user-supplied Assistant key (`LEADFNDR_API_KEY`); no key is bundled.
- Skills for connecting, finding and enriching leads, AI agents, Skill outreach, sending to CRM or webhooks, and acting in client sub-accounts.
